# Homework 4

We want to write a function to calculate the BMI value given height and weight of an individual.
Please refer to this [Wiki article](https://en.wikipedia.org/wiki/Body_mass_index)
for how BMI (Body mass index) is calculated.

Your task is to implement the `func_cal_bmi` function.
The function is defined in the `func_cal_bmi.R` file located in the `func` directory.
Only edit the `func_cal_bmi.R` file (located in the `func` directory), where it says ` # implement this function here`
Don't edit any other files in this repository.

Similar to [Homework 3](https://github.com/oxford-mgh-2526/intro-r-hw3),
we have a couple of `stopifnot` calls to check if your implementation is correct
when you push your branch up to this repository.
These are written in the `a_tester.R` file. Don't make any changes to this file.

You can find similar checks at the end of `func_cal_bmi.R` too without `stopifnot`.
These are for your convenience when you want to know if your implementation is correct.

## Hints

In addition to writing the code to implement the function, you should pay attention to

 - How the function is commented at the beginning of `func_cal_bmi.R`
 - How the `source` function works at the beginning of `a_tester.R`

## Submission

You should follow these steps:

- Clone this repository to your laptop
- Create and switch to your own branch (use your inital_surname as branch name, e.g. `b_gao` for Bo Gao)

- Edit the `func_cal_bmi.R` file (located in the `func` directory), where it says ` # implement this function here`

- Commit your changes once you are happy with it
- Push your branch back up to the GitHub repository
- Use the **link to your branch** of the repository as answer to the Teams assignment question.
